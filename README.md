# MediGo – Healthcare Monitoring Application

## Overview
MediGo is a UI/UX design project for a mobile healthcare application that helps patients with chronic diseases monitor their health conditions more effectively.

The application is designed to support continuous health monitoring by providing medication reminders, appointment scheduling, health record management, and communication between patients and healthcare providers.
